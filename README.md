# Tabla Taal Metronome

A web-based metronome for practicing Indian classical percussion (tabla) taals. Select from authentic beat cycles, adjust tempo and volume, and practice with visual beat markers for sam (beat 1), tali (clap), and khali (wave).

## Features

- **7 Authentic Taals**: Teentaal, Ektaal, Jhaptaal, Rupak, Dadra, Kehrawa, Bhajani
- **Visual Beat Display**: 2×8 grid showing each beat with theka syllables (bols)
- **Beat Marking**: Sam (gold), Tali (orange), Khali (teal) automatically highlighted
- **Tempo Control**: 20–300 BPM with slider, ±1 buttons, and tap-tempo
- **Volume Control**: Synthesized clicks (no audio files needed)
- **Stats**: Beat counter, vibhag counter, elapsed time in hh:mm:ss
- **Keyboard Shortcut**: Space bar to start/stop

## Try It

[Open the metronome](https://selfmodify.github.io/tabla-metronome/)

Or download and open `index.html` locally—it's a single self-contained file with no dependencies.

## Notes

The theka syllables shown are simplified, commonly-taught versions. Actual bol phrasing varies by gharana tradition.
